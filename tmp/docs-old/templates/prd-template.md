## 附：PRD 评审清单（评审会只讨论三类问题）

- [ ] **值不值得做**：问题证据充分？指标合理可量化？

- [ ] **怎么判定完成**：AC 是否可测试、无歧义、覆盖异常、可追溯？
- [ ] 依赖与风险是否已识别，上线/灰度/回滚是否有安排？
