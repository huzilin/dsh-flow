# 产品文档：盘前简报模块

## 1. 功能范围
盘前新闻聚合、自选股涨跌速览、事件提醒、本地持仓导入。

## 2. 验收标准
开盘前 30 分钟可完整加载；
宕机不阻塞浏览；
数据延迟 ≤ 5s。

## 3. 异常处理
行情源中断时展示降级横幅，并保留已加载内容。
开盘前 30 分钟可完整加载；+ 评论
