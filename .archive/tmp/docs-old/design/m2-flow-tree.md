## 1. 目标与范围

交付**需求详情页 = OA 流程树视图**。User 在此评审产出物、与产出者多轮对话、推动需求在各阶段流转。

**范围内**：流程树、评审状态行+角色对话区、产物阅读器（文档级/行级/范围级/块级评论）、门禁（通过/打回）、已解决评论折叠。

**不在范围内**（M3/M4/M5）：版本看板、需求池、收件箱、TODO。

## 3. 区域与交互（权威定义）

### 3.1 顶部条
需求标题 + 类别 + 状态 + 负责人（Leader）。「← 返回需求池」后置 M3。

### 3.2 左列：流程步骤列表
- 竖向列出流程实例全部节点（需求任务 19 / 规划审批 4 / 版本规划 11），**全展示不折叠**。
- 每节点：状态圆点（绿=已通过 / 黄=进行中|待评审 / 灰=未开始）+ 节点名 + `↩N`（回滚 N 次）。
- **节点独立**：一条流程标签 = 一个节点。点击切换右列详情。
- **前进/回退**：通过 → 前进下一节点；打回 → 回退上一节点。

### 3.3 右列：节点详情，含四区

**① 节点元信息**：负责人角色、进入时间、回滚次数、职责（职责文案 T3 起展示）。

**② 评审状态行（有 `reviewers` 的 review 节点才显示）**：
- 一行角色药丸：`Architect ✅` / `RD ✅` / `FE ⚠2未解决` / `QA ⚠轮14`（轮次 ≥10 且未解决 → 黄色高亮"疑似卡死"）。
- **点角色药丸 → 展开该角色的「意见 ↔ 被评审者反馈」对话区**：该角色名下每条评论是一条对话串（评审者提意见 → 产出者反馈 → 可多轮 + `roundCount`）。
- **User 三态参与**：
  1. **参与讨论**：在任一评论下「回复」；
  2. **普通 resolve**：把某条评论标「解决」（提问方/User 点「解决」按钮）；
  3. **强权干预**：对话区底部「强行通过 X 全部剩余」按钮（把该角色所有 open 评论 override）。
- 评审通过 = 该角色名下所有评论均 `resolved`/`overridden`。

**③ 产物区（文件行 → 飞书式阅读器）**：
- 节点绑定的产物以文件行展示：文件名（点开）+ 设计理念注记 + `💬N`（该产物评论数）。
- **点击文件名 → 弹窗阅读器**（见 §4）。

**④ 门禁区（`gate=true` 节点才显示）**：
- **评论解决进度**：`已解决/总数`（如 `2/6`）。**未全部解决时「通过」被拦截**（置灰，防误通过）。
- `[通过]`：全部评论 resolved 后可用 → 前进下一节点。
- `[打回]`：内联表单（必填理由 + 勾选"需重新界定新范围"）→ 回退上一节点，记 `rolledBackAt`，可选产生 `pendingScope`。

## 4. 产物阅读器（飞书式，核心交互）

### 4.1 布局
弹窗（约 72vw × 85vh），**正文占满宽度（无右侧栏）**，底部一条输入框。

### 4.2 正文渲染（轻量 markdown）
- **标题** `#`~`######` 放大加粗；
- **粗体** `**text**`、**行内代码** `` `code` ``；
- **围栏代码块** ``` ``` 识别为**整块**（等宽、深色底、顶部语言标签如 mermaid/json）；mermaid 只作代码块展示（不画图）。
- 每行左侧有灰色**行号**（1-based）。
- 列表/表格/引用暂未实现（后续）。

### 4.3 评论锚点（四级）
| 锚点 kind | 含义 | 数据字段 |
|---|---|---|
| `document` | 文档级（文末讨论） | `{kind:'document', artifactId}` |
| `line` | 单行 | `{kind:'line', artifactId, line, lineText}` |
| `range` | 多行范围 | `{kind:'range', artifactId, startLine, endLine}` |
| `block` | 整块（代码块/mermaid） | `{kind:'block', artifactId, blockStart, blockEnd, lang}` |

> 已废弃：`heading`/章节级（早期设计，已简化为「文档级 + 行级 + 范围 + 块」）。

### 4.4 行/范围选择交互（权威规则）
1. **点击一次** = 选中该行高亮（单行），可直接发表单行评论；
2. **点其他行** = 框选范围（起点~该行高亮区间）；
3. **重复点起点行** = 取消选择；
4. **框选后（已 1~3）再点任何行 C** = **重新开始**，仅高亮 C（不再扩展终点）。

底部输入框文案随选中状态变化：单行「对第 N 行评论」/ 范围「对第 A~B 行评论」/ 无选择「写文档评论…」。

### 4.5 评论展示
- **行级评论**：显示在对应行下方（内嵌，一一对应）；
- **范围评论**：**只在范围末行（endLine）下方显示一次**（不每行重复）；评论卡片带 `↔ A~B 行` 标记，**点击该标记 → 高亮整个范围**（独立视图高亮，不干扰新建选择）；
- **块级评论**：显示在代码块下方；
- **文档级评论**：显示在正文末尾。
- **有评论的行/块高亮**（浅蓝背景 + 左侧色条）；正在选中的行/范围高亮（黄色）。

### 4.6 评论卡片（评论 = 问题，统一模型）
- 每条评论：作者 + 文本 + 状态标（`未解决`/`已解决`/`已强制通过`）+ `roundCount`（轮次）。
- 每条评论有**子对话 thread**（谁都能回复）+ 「回复」输入框 +「解决」按钮（open 态才有）。
- **已解决（resolved/overridden）的评论默认折叠**成一行摘要（作者+文本截断+状态标+▸），点展开、展开后「收起▴」。

## 5. 数据字段（`<workspace>/.workbench/`）

```
requirements.json           # 需求列表
<reqId>/
  flow.json                 # 流程实例 + 节点状态（含 reviewers[]）
  artifacts.json            # 产物（文件行）
  comments.json             # 统一评论模型（含四种 anchor）
```

### comments.json（评论=问题，统一模型）
```json
[
  { "id": "cm-001", "requirementId": "req-001", "nodeId": "n-03",
    "anchor": { "kind": "document", "artifactId": "art-001" },
    "author": "User", "role": "user", "text": "…", "at": "…",
    "state": "open", "thread": [], "roundCount": 0 },

  { "id": "cm-003",
    "anchor": { "kind": "line", "artifactId": "art-001", "line": 13, "lineText": "宕机不阻塞浏览" },
    "author": "User", "role": "user", "text": "…", "state": "open" },

  { "id": "cm-r1",
    "anchor": { "kind": "range", "artifactId": "art-001", "startLine": 5, "endLine": 8 },
    "author": "User", "role": "user", "text": "…", "state": "open" },

  { "id": "cm-b1",
    "anchor": { "kind": "block", "artifactId": "art-001", "blockStart": 22, "blockEnd": 30, "lang": "mermaid" },
    "author": "User", "role": "user", "text": "…", "state": "open" }
]
```

> **state 状态机**：`open → resolved | overridden`。`resolved`（提问方/User 点「解决」或产出者改到满意）；`overridden`（User 强权「强行通过」）。
> **节点通过门禁** = 该节点名下所有评论 `resolved`/`overridden`（`已解决/总数` 全满才可通过）。

## 6. 已确认决策（v1.0 汇总）

1. 左列节点全展示，节点独立（一条标签一节点），通过前进/打回回退。
2. 评论 = 问题统一模型（不再分「评审 Issue」与「普通评论」），全要 resolved 才可通过门禁。
3. 评审状态行（角色药丸）+ 点角色展开对话区 + User 参与讨论/解决/强行通过。
4. 阅读器飞书式：整行可点、行内嵌评论、有评论行高亮、文档级输入区在正文底部。
5. 锚点四级：document / line / range / block（废弃 heading 章节级；diff 级后置 M8）。
6. 行选择：点一次=单行、点其他=框选、点起点=取消、框选后再点=重新开始。
7. 范围评论只在末行显示一次，`↔A~B` 标记点击高亮范围。
8. 已解决评论默认折叠。
9. 代码块整块评论；mermaid 按代码块展示（不画图）。
10. UI 字号整体 +1（比初始大一号）。
