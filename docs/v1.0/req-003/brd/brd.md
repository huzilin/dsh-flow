# 《评审通知复现需求》业务需求文档（BRD）

> 联调样例文档（BUG-015 数据修复入库，2026-09-10）。本需求为通知链路联调专用样例需求。

## 1. 需求背景

评审/门禁/缺陷各环节的通知触达需要可复现的样例数据支撑联调，本需求即为此构造。

## 2. 需求目标

- 构造覆盖提评、评审表态、拍板、缺陷 reopen、冲突上升全链路的通知场景。
- 收件箱七类通知投影均有对应样例数据可核。

## 3. 范围

- 范围：样例需求一条（business×full），逐步推进覆盖各通知触发点。
- 非范围：通知渠道扩展、阈值调整。

## 4. 验收标准

- 提评后对应角色收件箱出现 gate_pending 投影。
- 缺陷 reopen 后提评者收到 re_review 通知（target_id=issueId）。
- 冲突上升后仲裁人收到 escalation 投影。
