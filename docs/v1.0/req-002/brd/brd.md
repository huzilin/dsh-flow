# 《对账明细导出（联调）》业务需求文档（BRD）

> 联调样例文档（BUG-015 数据修复入库，2026-09-10）。内容为联调演示用样例，供文档阅读/锚定评论交互测试。

## 1. 需求背景与诉求

- 现状：对账明细目前只能在平台内查询，运营与财务每日人工截图导出，效率低且易漏。
- 痛点：月结对账窗口期，人工导出约占用 2 人日；截图无法二次加工。
- 诉求：提供明细的结构化导出能力，支持离线加工与归档。

## 2. 需求目标与成功标准

- 目标：运营可自助导出任意筛选条件下的对账明细。
- 成功标准：导出文件字段完整、金额合计与页面查询一致；导出耗时可接受。

## 3. 范围与非范围

- 范围：明细导出（CSV）、筛选条件继承、异步任务与完成通知。
- 非范围：报表订阅推送、多格式（Excel/PDF）导出、权限体系改造。

## 4. 用户与场景

- 财务专员：月末按商户与日期段导出全量明细，离线核对。
- 运营：按渠道导出当日差异明细，跟进差异处理。

## 5. 验收标准（AC）

- Given 筛选条件命中 0 条，When 导出，Then 生成仅含表头的空文件并提示。
- Given 筛选条件命中 N 条，When 导出完成，Then 文件行数 = N 且合计一致。
- Given 导出任务进行中，When 查询任务状态，Then 可见进度并可取消。

## 6. 遗留问题

- 超大数据量（百万行）导出的分片策略待技术方案确认。
