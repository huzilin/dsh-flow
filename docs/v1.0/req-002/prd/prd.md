# 《对账明细导出（联调）》产品设计文档（PRD）

> 联调样例文档（BUG-015 数据修复入库，2026-09-10）。

## 1. 问题陈述

运营与财务的对账明细导出目前依赖人工截图与手工整理，效率低、易出错、不可追溯。

## 2. 目标与成功指标

- 业务结果：明细导出自助率 100%，人工导出工时降为 0。
- 交付护栏：导出金额合计与查询页合计误差为 0；任务失败率 < 0.1%。

## 3. 范围与非范围

- In scope：CSV 导出、筛选继承、异步任务、完成站内通知。
- Out of scope：订阅推送、Excel/PDF、权限改造。

## 4. 用户与场景

- 财务专员（主路径）：选日期段 → 选商户 → 点导出 → 收到完成通知 → 下载文件。
- 运营（动机场景）：差异巡检中发现可疑渠道，即时导出当日明细核对。

## 5. 功能需求（AC 逐条）

1. 导出入口：明细查询页新增「导出」按钮，继承当前全部筛选条件。
2. 异步任务：点击后创建导出任务，页面出现任务进度条，可取消。
3. 完成通知：任务完成发送站内通知，点击直达下载。
4. 文件规范：UTF-8 CSV，首行表头，金额保留两位小数。

## 6. 依赖与风险

- 依赖：明细查询接口的翻页语义（导出复用其筛选契约）。
- 风险：大结果集导出的内存峰值，技术方案需给出分片写文件方案。
