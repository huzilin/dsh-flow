# 《逐步推进验证需求（正常流程构造）》RD 技术设计

> 联调样例文档（BUG-015 数据修复入库，2026-09-10）。

## 1. 方案概述

纯编排构造需求，不改服务端代码路径；技术设计记录推进脚本与断言口径，供复测复用。

## 2. 推进脚本设计

- 每步动作与断言封装为独立函数，顺序调用；
- 每步后拉取需求快照，断言流程位置与产物矩阵；
- 角色令牌按 seed 角色表切换（pm/arch/rd/fe/qa）。

## 3. 断言口径

| 断言维度 | 口径 |
|---|---|
| 流程位置 | flows.current_node_id 逐步前移 |
| 产物矩阵 | 每节点 expected_outputs 逐一登记且 kind=document |
| 需求状态 | BUG-001 修复后随推进联动（收尾→已完成） |
| 审计 | 关键写路径 by_who 归属正确 |

## 4. 风险

- 推进中途停等需人工/agent 扮演 gate 角色——由驱动脚本自动扮演。
