# 《逐步推进验证需求（正常流程构造）》业务需求文档（BRD）

> 联调样例文档（BUG-015 数据修复入库，2026-09-10）。本需求为状态联动复现（BUG-001）构造的正规编排样本。

## 1. 需求背景

验证「流程推进 ↔ 需求状态」联动需要一条按正规编排逐步推进的需求样本，避免速推数据伪影。

## 2. 需求目标

- business×full 模板 13 节点逐步推进，每步可观测需求状态与流程位置。
- 为 BUG-001（状态零联动）提供 1:1 复现载体。

## 3. 范围

- 范围：单条 business×full 需求，推进至 RD 技术评审停等。
- 非范围：并行 join 序、打回重定分支（另有剧本覆盖）。

## 4. 验收标准

- 每步推进后需求快照（flows/flowNodes/artifacts）自洽。
- 收尾节点通过后需求状态应为「已完成」（spec §7.3 口径，BUG-001 修复后生效）。
